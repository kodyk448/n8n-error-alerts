# Images in this repository

The share image, the closing art, the workflow diagrams (desktop and mobile SVG) and the alert previews were made for this repository by Dakota Kronberger / Future Built Digital. The Ko-fi support banner was supplied by Dakota.

The alert previews show example data (a made-up workflow name, error and link) so you can see what the messages look like. They are drawings, not screenshots of Slack.
